# Real Completion Policy

A workstream is complete only when all applicable layers are verified:

1. Owner Supabase schema, RLS, functions, triggers, indexes and data flow.
2. Admin frontend with beginner-safe loading, error, empty, success and mobile states.
3. Existing public website integration where applicable.
4. TypeScript, tests, production build and release guards pass.
5. Lovable sync and production publish complete.
6. Live smoke evidence confirms the feature uses owner Supabase.
7. No unsupported business claim, automatic commercial commitment or hidden manual step.

Planning documents, mock buttons, placeholder cards, local-only state and unverified connector claims are not completion evidence.
