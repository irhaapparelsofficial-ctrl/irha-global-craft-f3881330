# Batch 2 Lederhosen Media

This isolated media batch contains verified four-view image packs for:

- Traditional Knee-Length Lederhosen
- Premium Embroidered Lederhosen

Each product includes:

- four clean 2048 × 2048 PNG masters;
- four branded 2048 × 2048 PNG masters using the exact locked Irha Apparels raster logo;
- four web-optimized 1600 × 1600 WebP files;
- a product manifest containing source dimensions, output paths and SHA-256 checksums.

The media generator validates image MIME type, file size, square dimensions and minimum resolution before producing final files. Production product records are intentionally unchanged in this pull request; live gallery mapping requires a separate identity-safe database step.
