# Lead Acquisition Engine v1 release checklist

- Admin-only campaign, candidate and search-run tables with RLS
- Public-source discovery through Firecrawl-compatible backend credentials
- AI classification that forbids invented fields
- Evidence and exact source URLs stored with every candidate
- Website enrichment before automatic verification
- Domain and email duplicate detection
- Manual verify/reject controls
- Verified-only import into the existing Buyer CRM
- CSV export and exact runtime health states
- No automatic outreach or fake completion claims
