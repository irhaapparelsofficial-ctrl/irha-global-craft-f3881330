# Irha Apparels — Real Completion Tracker

This tracker records only features that are connected to live systems and tested. A feature is not marked complete merely because a screen or placeholder exists.

## Completion standard

A feature can be marked complete only when:

1. It reads or writes the owner Supabase project.
2. Admin authorization and RLS are preserved.
3. Empty, loading, error, success, and retry states exist.
4. It works on iPhone and desktop.
5. Automated quality checks pass.
6. A production smoke test is completed after publish.
