# Admin Outreach Command Center v1

## Purpose

Connect the existing evidence-backed lead research queue to Buyer CRM and the existing AI Outreach Engine without bypassing owner approval.

## Included

- Admin-only floating AI Outreach command center.
- Strict readiness checks before a candidate can be approved for CRM import:
  - valid business email;
  - website or domain;
  - buyer type;
  - product fit;
  - source URL and stored verification evidence;
  - verification score of at least 70.
- Owner-confirmed review and CRM import through the existing `lead-research` Edge Function.
- Candidate-review CSV export.
- Buyer CRM CSV export.
- Outreach subject/body/status CSV export.
- Clear handoff to the existing Mailing workflow.

## Explicit boundaries

- No email or WhatsApp message is generated by this bridge.
- No email or WhatsApp message is approved by this bridge.
- No email or WhatsApp message is sent by this bridge.
- Existing Mailing and WhatsApp approval/send boundaries remain unchanged.
- No database migration, product change, media change, pricing commitment, MOQ promise, delivery promise or certification claim is introduced.

## Daily owner flow

1. Review strict-ready candidates.
2. Approve and import selected companies into Buyer CRM.
3. Open Mailing and generate personalized drafts.
4. Review each subject and body.
5. Approve correct messages only.
6. Select approved messages and confirm the irreversible send action separately.
