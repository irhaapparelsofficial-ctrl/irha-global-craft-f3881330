# IA-CONTENT-E001 — Public-string register

This register separates public presentation language from protected internal/admin operations.

| Phrase family | Public classification | Public action | Internal/admin action |
|---|---|---|---|
| Digital reference / digital catalogue reference | Buyer-facing artificial/internal label | Remove or convert to neutral product-style wording in final artifacts | Not required for operations |
| Pending / media pending / photography pending / awaiting upload | Buyer-facing incompleteness | Remove from public output; use controlled official-brand fallback | Preserve genuine workflow states in admin tools |
| AI generated / AI image / AI concept | Buyer-facing artificial label | Remove from public presentation; retain only required legal limitation wording where applicable | Preserve internal generation diagnostics |
| Placeholder / demo / prototype / sample content | Buyer-facing development language | Remove from public DOM, metadata and shells | Preserve code/test terminology where not exposed |
| New/newly built website / under development | Buyer-facing incompleteness | Replace with factual requirement-led manufacturing language | Preserve historical/internal documentation where needed |
| Image unavailable / question-mark fallback | Technical fallback language | Replace with official Irha Apparels identity and stable accessible behavior | Keep failure diagnostics machine-readable |
| ISO/OEKO-TEX/SEDEX/WRAP/BSCI/GOTS/GRS certified/approved/compliant | Unsupported compliance claim risk | Block unless exact authenticated evidence exists | Preserve internal review records only |
| Inquiry/production/upload/moderation/security scan status | Operational state | Must not leak into public DOM or metadata | Preserve in authenticated admin surfaces |

## Locale rule

Equivalent prohibited presentation language is blocked in English, German, French and Dutch deployable output. Route slugs and localized navigation remain unchanged.
