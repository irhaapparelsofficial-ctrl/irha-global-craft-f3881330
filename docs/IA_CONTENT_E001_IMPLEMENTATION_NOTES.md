# IA-CONTENT-E001 — Implementation notes

Public sanitation runs late in the existing build chain so generated route shells, compiled JavaScript, metadata, JSON-LD, crawler output and localized assets are all covered. The guard reports pre-sanitation counts and fails if prohibited presentation language or unsupported certification claims remain after sanitation.

Internal/admin workflow terminology is not rewritten at source. Product-source media files are unchanged. Official crest treatment is applied as UI chrome and controlled fallback branding only.
