## 1. Project Overview

**Vision.** B2B garment-manufacturing platform for Irha Apparels (Sialkot, Pakistan) targeting importers in DE, AT, CH, UK, US, CA, AU, AE. The site sells "made-to-order" tailored apparel (lederhosen, dirndls, business suits, uniforms, sportswear) to wholesalers and private-label buyers — not end consumers. Everything on the site funnels to: (a) an inquiry / quote form, (b) a catalogue lead form, (c) a live chat, or (d) a custom-mockup request. Admin manages products, leads, content, pricing, and social posting from `/admin`.

**Delivered features.**
- Public marketing site (30 routes) with a Lederhosen-first homepage.
- Products (64 live) organised into 26 categories with SEO-friendly deep URLs `/products/:category/:product`.
- Digital catalogue at `/catalogue` with flipbook + lead-capture gating.
- Multi-country SEO landings + occasion / location / keyword landing pages (~900 URLs in sitemap).
- Blog + Journal + FAQ + Compliance + Sustainability content routes (content currently hardcoded in `src/lib/`).
- Quote/Inquiry forms → `inquiries` table; catalogue leads → `catalogue_leads`; contact chat → `chat_messages`.
- Admin dashboard at `/admin` (Google OAuth, `has_role(admin)` gated) with 12 panels.
- Live chat widget + admin chat responder (edge function `admin-chat`).
- Custom Mockup Studio (`/studio`) with a zoned silhouette configurator + FOB price calculator.
- Email queue infrastructure (pgmq + pg_cron + edge function `process-email-queue`).
- Social publisher scaffolding (`social-publish`, `social-multi-sync`) for Meta / LinkedIn / TikTok.
- Google Search Console analytics (`gsc-analytics`, `gsc-inspect`) surfaced in the admin.
- Prerender pipeline (`react-snap`) for SEO, structured data, hreflang, sitemap ping.
